Все нужные операции с PDF — в одном месте

Объединяйте документы, разделяйте страницы и конвертируйте изображения. Без установки программ и регистрации.

✓ Файлы обрабатываются прямо в вашем браузере
⇄

Объединить PDF

Соберите несколько PDF в один документ. Порядок файлов можно менять кнопками ↑ ↓.

    ▤

    Разделить PDF

    Сохраните каждую страницу отдельным PDF-файлом. Результат скачивается архивом ZIP.

      ▧

      Изображения → PDF

      Создайте многостраничный PDF из изображений JPG, PNG или WebP.

        ▨

        PDF → изображения

        Экспортируйте страницы документа в PNG или JPG. Все страницы попадут в ZIP-архив.

          Aa

          OCR — распознать текст

          Извлеките текст из сканов, фотографий или PDF. Распознавание выполняется в браузере; исходные файлы не отправляются на сервер.

            ▤

            Сканирование документов

            Выберите сканер или МФУ, подключённое к этому компьютеру по USB или доступное в локальной сети. Для обнаружения USB-устройств нужен локальный помощник Windows.

            Запусти start_local_bridge.bat и оставь окно открытым. Сначала проверь подключение, затем нажми «Сканировать».
            \n
            Ограничения браузерной версии: OCR распознаёт текст из PDF и изображений локально в браузере. Прямое сканирование обычных USB-устройств через WIA/TWAIN без установки помощника невозможно; сетевые сканеры поддерживаются только при совместимости с eSCL/AirScan и разрешении соединения браузером. Word/Excel пока не конвертируются. Для больших документов может потребоваться больше оперативной памяти.
            DocuDesk Web · Файлы не отправляются на сервер приложения. Для работы используются библиотеки PDF.js, pdf-lib и JSZip с CDN.
