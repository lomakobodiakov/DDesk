DocuDesk Web
Инструменты для документов прямо в браузере
Веб-версия · 0.1

Все нужные операции с PDF — в одном месте

Объединяйте документы, разделяйте страницы и конвертируйте изображения. Без установки программ и регистрации.

✓ Файлы обрабатываются прямо в вашем браузере
⇄

Объединить PDF

Соберите несколько PDF в один документ. Порядок файлов можно менять кнопками ↑ ↓.

    ▤

    Разделить PDF

    Сохраните каждую страницу отдельным PDF-файлом. Результат скачивается архивом ZIP.

      ▧

      Изображения → PDF

      Создайте многостраничный PDF из изображений JPG, PNG или WebP.

        ▨

        PDF → изображения

        Экспортируйте страницы документа в PNG или JPG. Все страницы попадут в ZIP-архив.

          Важно: веб-версия пока не подключается к физическим сканерам, не выполняет OCR и не конвертирует Word/Excel. Эти функции остаются в планах/настольной версии. Для больших документов может потребоваться больше оперативной памяти.
          DocuDesk Web · Файлы не отправляются на сервер приложения. Для работы используются библиотеки PDF.js, pdf-lib и JSZip с CDN.
