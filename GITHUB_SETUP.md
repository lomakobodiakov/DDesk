# Как опубликовать DocuDesk на GitHub без командной строки

## 1. Создать репозиторий

1. Откройте https://github.com/new и войдите в свой аккаунт.
2. Repository name: `DocuDesk`.
3. Выберите `Public` или `Private` по своему усмотрению.
4. Не добавляйте README, `.gitignore` или лицензию при создании — они уже есть в проекте.
5. Нажмите **Create repository**.

## 2. Загрузить файлы проекта

1. Распакуйте архив исходного проекта на компьютере.
2. Откройте созданный репозиторий на GitHub.
3. Нажмите **Add file → Upload files**.
4. Перетащите содержимое папки проекта в окно загрузки. Убедитесь, что папка `.github/workflows` и файл `.github/workflows/windows-release.yml` тоже загружены. В браузере загрузка скрытых папок иногда неудобна; если `.github` не удаётся загрузить, используйте GitHub Desktop (см. ниже).
5. Внизу страницы нажмите **Commit changes**.

## Надёжный способ загрузить скрытую папку `.github`

Если веб-интерфейс не показывает скрытые файлы, установите GitHub Desktop: https://desktop.github.com/ . В нём выберите **File → Clone repository**, клонируйте пустой репозиторий, скопируйте в локальную папку все файлы проекта (включая `.github`) и нажмите **Commit to main → Push origin**.

## 3. Запустить сборку

1. В репозитории откройте вкладку **Actions**.
2. Если GitHub просит включить Actions, подтвердите.
3. Выберите workflow **Build Windows releases**.
4. Нажмите **Run workflow → Run workflow**.
5. Дождитесь зелёной галочки.

## 4. Скачать сборки

Откройте завершённый запуск workflow и найдите раздел **Artifacts** внизу страницы. Скачайте `DocuDesk-Windows-builds` — ZIP содержит установщик и portable ZIP.

Для публикации постоянного релиза с файлами на вкладке **Releases** создайте тег версии, например `v0.1.0`. При отправке такого тега workflow автоматически соберёт приложение и прикрепит файлы к GitHub Release. Для первой проверки достаточно кнопки **Run workflow**.

## Примечания

- Сборка выполняется на Windows runner GitHub Actions; локально устанавливать Python для сборки не требуется.
- Portable-версия — это ZIP с папкой приложения; распакуйте его и запустите `DocuDesk.exe`. Не переносите один EXE отдельно от остальных файлов папки.
- Приложение пока не подписано цифровым сертификатом, поэтому Windows SmartScreen может показать предупреждение.
- Успешная сборка не заменяет проверку на реальном Windows-компьютере и тестирование с конкретным сканером/МФУ.
